# جمعية إمليل للتنمية والتعاون

موقع ويب رسمي لجمعية إمليل للتنمية والتعاون في دوار أيت سعيد أوداود ب  إميضر، المغرب.

## نظرة عامة

هذا المشروع عبارة عن تطبيق ويب حديث ومتجاوب تم تطويره باستخدام React و TypeScript، مخصص لإدارة أنشطة الجمعية وتقديم المعلومات للمجتمع المحلي.

## الميزات الرئيسية

### 🏠 الصفحة الرئيسية
- عرض ترحيبي للجمعية
- نظرة عامة على الأنشطة
- معلومات الاتصال
- تصميم متجاوب وجذاب

### 📋 إدارة الأنشطة
- عرض جميع أنشطة الجمعية
- تصنيف الأنشطة حسب النوع
- نظام فلترة وبحث متقدم
- إدارة حالات الأنشطة (مخطط، جاري، مكتمل)

### 📅 إدارة الفعاليات
- عرض الفعاليات القادمة والجارية والمكتملة
- نظام تسجيل للمشاركين
- إدارة الحد الأقصى للمشاركين
- تقويم تفاعلي

### 🖼️ معرض الصور
- عرض صور الأنشطة والفعاليات
- نظام تصنيف للصور
- معاينة الصور في وضع ملء الشاشة
- إمكانية التنقل بين الصور

### 📰 نظام الأخبار
- نشر الأخبار والإعلانات
- تصنيف الأخبار
- نظام نشر/مسودة
- معاينة تفصيلية للأخبار

### 👥 إدارة الأعضاء
- تسجيل أعضاء جدد
- إدارة بيانات الأعضاء
- نظام أدوار المستخدمين

### ⚙️ لوحة الإدارة
- إدارة شاملة لجميع المحتويات
- إضافة وتعديل وحذف البيانات
- تحميل البيانات التجريبية
- واجهة سهلة الاستخدام

## التقنيات المستخدمة

### Frontend
- **React 18** - مكتبة واجهة المستخدم
- **TypeScript** - لغة البرمجة
- **Vite** - أداة البناء والتطوير
- **Tailwind CSS** - إطار عمل CSS
- **Shadcn/ui** - مكتبة مكونات UI
- **React Router** - إدارة التنقل
- **React Hook Form** - إدارة النماذج
- **Zod** - التحقق من صحة البيانات

### State Management
- **React Context API** - إدارة الحالة
- **LocalStorage** - تخزين البيانات محلياً

### Icons & Assets
- **Lucide React** - مكتبة الأيقونات
- **Hero Image** - صورة الخلفية الرئيسية

## التثبيت والتشغيل

### المتطلبات
- Node.js (الإصدار 18 أو أحدث)
- npm أو yarn

### خطوات التثبيت

1. **استنساخ المشروع**
   ```bash
   git clone https://github.com/your-username/imlil-atlas-roots.git
   cd imlil-atlas-roots
   ```

2. **تثبيت التبعيات**
   ```bash
   npm install
   # أو
   yarn install
   ```

3. **تشغيل المشروع في وضع التطوير**
   ```bash
   npm run dev
   # أو
   yarn dev
   ```

4. **فتح المتصفح**
   انتقل إلى `http://localhost:5173`

### بناء المشروع للإنتاج

```bash
npm run build
# أو
yarn build
```

## هيكل المشروع

```
src/
├── components/          # المكونات القابلة لإعادة الاستخدام
│   ├── ui/             # مكونات واجهة المستخدم الأساسية
│   ├── Navbar.tsx      # شريط التنقل
│   ├── Hero.tsx        # القسم الرئيسي
│   ├── Activities.tsx  # قسم الأنشطة
│   ├── About.tsx       # قسم من نحن
│   ├── Contact.tsx     # قسم الاتصال
│   └── Footer.tsx      # التذييل
├── contexts/           # إدارة الحالة
│   └── AppContext.tsx  # السياق الرئيسي للتطبيق
├── pages/              # صفحات التطبيق
│   ├── Index.tsx       # الصفحة الرئيسية
│   ├── Register.tsx    # صفحة التسجيل
│   ├── ActivitiesList.tsx # صفحة الأنشطة
│   ├── Events.tsx      # صفحة الفعاليات
│   ├── Gallery.tsx     # صفحة المعرض
│   ├── News.tsx        # صفحة الأخبار
│   ├── Admin.tsx       # لوحة الإدارة
│   └── NotFound.tsx    # صفحة 404
├── data/               # البيانات التجريبية
│   └── sampleData.ts   # بيانات العينة
├── hooks/              # الخطافات المخصصة
├── lib/                # المكتبات المساعدة
└── assets/             # الأصول الثابتة
```

## التخصيص

### الألوان
يمكن تخصيص نظام الألوان من خلال تعديل متغيرات CSS في `src/index.css`:

```css
:root {
  --primary: 158 64% 52%;        /* اللون الأساسي */
  --secondary: 210 100% 48%;     /* اللون الثانوي */
  --accent: 158 64% 52%;         /* لون التمييز */
  /* ... */
}
```

### المحتوى
يمكن تخصيص المحتوى من خلال:
- تعديل البيانات في `src/data/sampleData.ts`
- تحديث النصوص في المكونات
- إضافة صور جديدة في مجلد `public/`
